Vous êtes sur le point d'apprendre les sélecteurs CSS ! Les sélecteurs déterminent à quels éléments appliquer des styles.

Exemple 1 - Une règle CSS

p {
   margin-bottom: 12px;
}

Ici, le "p" est le sélecteur (sélectionne tous les éléments <p>) et applique le style margin-bottom.

Pour jouer, tapez un sélecteur CSS dans l'éditeur ci-dessous pour sélectionner les bons éléments sur la table. Si vous trouvez la bonne réponse, vous passerez au niveau suivant.

Survolez les éléments sur la table pour voir leur structure HTML.
